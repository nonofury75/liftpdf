# LiftPDF Phase 69 Authority Plan

## Objective

Build authority around LiftPDF's strongest real differentiators: browser-side PDF processing, practical PDF workflows, and transparent limits. This is not a bulk backlink campaign. The plan prioritizes credible placements where the content would still make sense if search traffic did not exist.

## Positioning Pillars

1. Browser-side PDF processing for supported tasks.
2. Practical PDF workflow education: merge, split, compress, image conversion, security, text extraction.
3. Honest security language: PDF permissions are useful but not DRM; unlocking requires the valid password or permission.
4. Device-aware large-file handling: browser tools depend on memory, browser and file complexity.

## Qualified Prospect Types

| Prospect type | Why it fits | Suggested angle | Priority |
| --- | --- | --- | --- |
| Privacy-focused software directories | LiftPDF has a clear no-upload workflow for supported tools | "Browser-side PDF processing for everyday documents" | High |
| Education and student resource pages | Image-to-PDF, merge and compress are common student workflows | "Free browser PDF tools for assignments and submissions" | High |
| Small business resource lists | PDF merge, compress, password protection and watermark workflows match admin work | "Private PDF utilities for invoices, contracts and forms" | High |
| Productivity blogs | Guides and tools create useful workflow references | "How to handle common PDF tasks without desktop software" | Medium |
| Open-source / privacy newsletters | QPDF WASM and browser processing are technically interesting | "Local PDF processing in the browser, with honest limits" | Medium |
| Design or image workflow resources | JPG/PNG to PDF and PDF to image workflows are strong | "Prepare image-heavy PDFs without uploads" | Medium |

## Outreach Rules

- Do not buy links.
- Do not use automated spam outreach.
- Do not promise unlimited file size or perfect compression.
- Do not claim LiftPDF replaces Acrobat for every professional workflow.
- Link to the most specific page, not always the homepage.
- Prefer tool plus guide pairs, for example `/compress-pdf` plus `/guides/how-to-compress-pdf-without-losing-quality`.

## First 30 Days

1. Submit LiftPDF to 10-15 relevant software/productivity directories with accurate privacy wording.
2. Pitch 5 privacy or productivity newsletters with the browser-processing angle.
3. Ask for inclusion on 10 education/resource pages where PDF utilities are already listed.
4. Publish no more than 2-3 supporting comparison/problem guides if Search Console data shows a clear gap.
5. Track impressions, exact queries, referral traffic and guide-to-tool clicks before adding new clusters.

## Measurement

- Search Console: discovered URLs, indexed URLs, impressions, exact queries.
- GA4: guide to tool clicks, tool opens, conversions, downloads after accepted consent.
- Logs/checks: 404s, broken internal links, unexpected canonical drift.

# LiftPDF 1.0.0

Release date: 2026-08-12

LiftPDF 1.0.0 is the first frozen production release of the V1 tool surface.

## Included Tools

LiftPDF V1 includes 17 browser-based PDF tools:

1. JPG to PDF
2. PNG to PDF
3. Images to PDF
4. Merge PDF
5. Split PDF
6. Compress PDF
7. PDF to JPG
8. PDF to PNG
9. Rotate PDF
10. Add Page Numbers
11. Watermark PDF
12. Delete Pages
13. Extract Pages
14. Reorder Pages
15. Protect PDF
16. Unlock PDF
17. PDF to Text

## Major Capabilities

- Convert JPG, PNG and mixed image batches into PDF.
- Convert PDF pages to JPG or PNG with page targeting and large-document safeguards.
- Merge PDFs with per-file validation and editable output filenames.
- Split PDFs by ranges, every page or fixed page intervals.
- Delete, extract, reorder and rotate pages with visual previews.
- Add page numbers with targeting controls.
- Add text or image watermarks above or below page content, including odd/even/range targeting.
- Compress PDFs with real QPDF WASM modes and optional metadata removal.
- Protect PDFs with AES-256, user/owner passwords and permission flags.
- Unlock PDFs when the user knows the valid user or owner password, including restriction-only PDFs.
- Extract selectable text from all pages or selected ranges.

## Privacy

V1 tool workflows are designed for local browser processing. Files and passwords are not uploaded to a LiftPDF backend for the supported V1 tools.

Analytics is optional. GA4 loads only after analytics consent is accepted. Tool analytics intentionally avoids filenames, document content, extracted text, passwords, local file paths and custom output filenames.

## Browser Support

Validated release targets:

- Chromium desktop
- Chromium mobile viewport
- Firefox desktop

The most demanding workflows depend on browser memory, PDF complexity and WebAssembly support.

## Known Limitations

- No OCR in V1.
- PDF to Text extracts selectable text only.
- PDF permissions are compatible-reader instructions, not DRM.
- Signed PDFs may lose signature validity after modification.
- Very large files depend on device memory and browser resources.
- Below-content watermarks are below page content streams, not necessarily below annotations/widgets.
- Corrupt or unsupported PDFs may be rejected.
- Compression savings depend on document structure.

See `docs/v1-known-limitations.md` for the full limitation register.

## Monetization Gate

Do not start monetization until:

- GA4 shows sustained users and successful jobs;
- at least 3 tools show meaningful usage;
- Search Console shows growing impressions/clicks;
- no critical errors dominate the funnel;
- a monetization model can preserve trust.

Compare:

| Model | Start condition | Risk |
|---|---|---|
| Ads | Meaningful traffic and low UX disruption | Can damage trust if aggressive. |
| Premium | Clear high-use workflows needing extras | Risk of locking core utility too early. |
| API | Repeated developer demand | Different product and infra. |
| Licensing | Enterprise/privacy demand | Requires support/compliance maturity. |

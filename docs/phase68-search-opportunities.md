## Classification Rule After Import

Use:

- `WINNING`: clicks and conversions already strong.
- `QUICK_WIN`: relevant query, real impressions, position can reasonably improve, existing page matches intent.
- `EMERGING`: low clicks but growing impressions.
- `LOW_CTR`: impressions and position exist, CTR underperforms.
- `HIGH_POSITION_GAP`: relevant but ranking too low for short-term traffic.
- `LOW_DATA`: insufficient sample.
- `IRRELEVANT`: query does not match LiftPDF's real tool or promise.

## Submission Copy

Short:

```text
LiftPDF is a browser-based PDF toolkit with 17 tools for merging, compressing, converting, protecting, unlocking and organizing PDFs. V1 focuses on local processing, practical workflows and honest limitations.
```

Long:

```text
LiftPDF helps users handle common PDF workflows directly in the browser: merge PDFs, split pages, compress files, convert JPG/PNG/PDF pages, add watermarks and page numbers, protect or unlock PDFs with known passwords, reorder/delete/extract pages and extract selectable text.

Files and passwords stay local for V1 tools. LiftPDF does not claim OCR, password recovery, unlimited file size or guaranteed exact compression targets.
```

# LiftPDF First 30 Days Acquisition Plan

Date: 2026-08-12

Goal order:

```text
TRAFFIC -> REAL USERS -> TOOL USAGE -> CONVERSIONS -> RETENTION -> REVENUE
```

## Week 0 - Baseline

- Capture GA4 Realtime proof after consent acceptance.
- Export Search Console Performance and Pages reports.
- Record current indexed/discovered status.
- Confirm `/sitemap.xml` and `/robots.txt` remain healthy.
- Set up the daily dashboard from `docs/launch-daily-dashboard-template.md`.

## Week 1 - Controlled Launch

Focus: feedback and real workflows.

- Product Hunt launch, if assets and maker availability are ready.
- Show HN submission with technical framing.
- 3-5 careful Reddit/community posts only where allowed.
- Submit to 5 high-quality directories.
- Monitor Tier A tool funnels daily.
- Fix only critical bugs, privacy issues, broken pages, or major conversion blockers.

## Week 2 - Search Feedback Loop

Focus: existing pages, not new page volume.

- Review Search Console queries with impressions.
- Improve titles/meta/internal links only for pages already receiving impressions.
- Identify guide-to-tool drop-offs.
- Add small FAQ/content clarifications only where users search for the exact issue.
- Continue directory outreach.

## Week 3 - Trust And Backlinks

Focus: durable mentions.

- Pitch privacy-first PDF toolkit angle to newsletters/directories.
- Add 10 more manual backlink prospects.
- Ask early users for workflow feedback.
- Watch for high error-rate tools.
- Do not start new P2 features unless a critical launch blocker appears.

## Week 4 - Decision Review

Focus: decide V1.1 from data.

- Rank tools by tool opens, upload starts, conversions, downloads and errors.
- Rank pages by impressions, clicks, CTR and average position.
- Identify the top 3 conversion leaks.
- Decide whether the next phase should be product reliability, content refresh, or one measured feature.

## Guardrails

- No mass SEO batches.
- No fake comparison pages.
- No claims not backed by the V1 matrices.
- No analytics fields containing file names, content, passwords or custom filenames.
- No paid backlink packages.

## Weekly Success Criteria

| Week | Success signal |
|---|---|
| 1 | Real users complete at least one Tier A tool workflow. |
| 2 | Search Console shows query/page signals that can guide edits. |
| 3 | At least 5 relevant external mentions/submissions are live or pending. |
| 4 | A data-backed V1.1 priority list exists. |
